yaml-based centralized platform for Hack Club Hackathons + Experiences.

try it out at https://hc-experiences.vercel.app/!

## features
- centralized directory for Hack Club events
- YAML-based event configuration for easy management
- static HTML/CSS/JS frontend with no backend
- responsive event display and filtering
